# LeetMetrics_Project
LeetMetrics is a simple and visually engaging web application that tracks and displays your LeetCode statistics. Built using HTML, CSS, and JavaScript, it fetches and displays your problem-solving progress, rankings, and other relevant metrics using LeetCode’s public data.

## 🚀 Features

- 🔍 Fetch LeetCode user data by username
- 📈 Display total solved problems and breakdown by difficulty
- 💡 Responsive design for mobile and desktop
- 🌐 No backend – runs entirely in the browser
